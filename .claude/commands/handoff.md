description: Session-Handoff schreiben bevor Kontext komprimiert/beendet wird
---

Erstelle einen Handoff für die aktuelle Session in `HANDOFFS/YYYY-MM-DD-<kurzbeschreibung>.md`.

Struktur:

## Status
Was war das Ziel dieser Session? Ist es erreicht, teilweise, oder blockiert?

## Erledigt
- Konkrete Änderungen (Dateien, Funktionen, Migrationen)
- Getroffene Entscheidungen UND deren Begründung (nicht nur "was", sondern "warum")

## Offen
- Was ist als nächstes zu tun
- Bekannte Probleme / TODOs, die bewusst zurückgestellt wurden

## Wichtiger Kontext
- Annahmen, auf die sich Code verlässt
- Dinge, die NICHT offensichtlich aus dem Code hervorgehen
- Trade-offs, die abgewogen wurden (und warum so entschieden wurde)

## Nächste Schritte
Konkrete, priorisierte Liste für die nächste Session.

Halte es präzise – Ziel ist, dass eine neue Session ohne Chatverlauf sofort produktiv weiterarbeiten kann. Kein Fluff, keine Wiederholung von Dingen, die schon in CLAUDE.md stehen.
